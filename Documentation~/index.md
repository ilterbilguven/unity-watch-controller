# Apple Watch Controller guide

This guide is for Unity developers who are new to Watch input. You do not need Unity Pipeline, Rider, a command-line workflow, or any other project to use the package.

Start with [installation](installation.md) and [getting started](getting-started.md). The first walkthrough proves input inside the Editor before you attempt signing or deployment.

- [Watch UI](watch-ui.md): author and export a native Watch interface.
- [Input System](input-system.md): bind game actions to the custom device.
- [Motion and audio](motion-and-audio.md): read units, tracked poses, meters, and recording files.
- [Build and test](build-and-test.md): export Xcode projects and separate validation stages.
- [Samples](samples.md): import and open each example.
- [Troubleshooting](troubleshooting.md): start at the earliest failing stage.
- [Contributing](contributing.md): source boundaries and optional contributor tools.

See the [package overview](../README.md), [changelog](../CHANGELOG.md), and [licenses](../Third%20Party%20Notices.md).
